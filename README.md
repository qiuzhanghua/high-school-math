| `排列组合15涂色问题.typ` | 排列·区域/顶点涂色（2 例）：以"有公共边界"为相邻、画相邻关系图、从相邻最多的区域入手/按"相间区域是否同色"分类、环形公式 `(k-1)ⁿ + (-1)ⁿ(k-1)`、不涂色区域的隔断作用；例题 街心花园（`A,B,C,D` 围成一圈、中心 `E` 为塑像不涂色）用 4 种花种植且相邻不同 ⟹ 按"`A` 与 `C` 是否同色"分类 `4×3×3 + 4×3×2×2 = 36+48 = 84`，选 **D**（递推法 `4×3×(1×3+2×2) = 84` 与公式 `3⁴+3 = 84` 验证，文档含区域示意图）；② 轮形图（五边形 `A..E` + 中心 `O` 五条辐条）用 5 色给 6 点涂色、相邻不同 ⟹ 先涂 `O`（5 种），外圈只能用其余 4 色且是五元环：`3⁵-3 = 240`，共 `5 × 240 = 1200`，选 **D**（附五元环 `72+72+96 = 240` 的手工分类验证，文档含轮形图） |

## 构建

```powershell
# 编译全部文档（自动跳过 template.typ）
./build.ps1

# 只编译指定文档（可省略 .typ 扩展名）
./build.ps1 -Only 圆锥曲线硬解定理

# 输出 PDF 到指定目录
./build.ps1 -OutputDir dist
```

macOS / Linux 使用等价的 Bash 脚本：`./build`（参数示例：`./build 蒙日圆及其反向应用`、`./build -o dist`）。

> 所有文档共用根目录下的 `template.typ`，用法为
> `#import "template.typ": *` 后用 `#template(...)[正文]` 包裹正文，
> 可选 `#set document(title: [...])` 在页眉右侧显示标题。
> 模板内置 `#definition`、`#important-block`、`#example`、`#theorem`、
> `#proof` 环境块，并提供页眉标题、页码/页脚（文档中通常传
> `page-footer: "第 1 页"`）、首行缩进、公式编号、字号等排版选项
> （详见模板文件头部注释）。
>
> 新增文档时仿照现有文档写即可，例如：
>
> ```typst
> #import "template.typ": *
> #set document(title: [题目或主题])
> #template(page-footer: "第 1 页")[ ……正文…… ]
> ```

编译产物为与源文件同名的 `.pdf`（已加入 `.gitignore`，不纳入版本管理）。
