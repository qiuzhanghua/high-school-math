# High School Math

高中数学（圆锥曲线）Typst 文档集：专题定理、公式与结论，以及近年高考、联考真题的完整解析，均使用共享模板 `template.typ` 排版。

## 文档

### 专题

| 文件 | 内容 |
|------|------|
| `椭圆焦半径.typ` | 椭圆焦半径公式：定义、代数法与几何法证明、推论与典型应用 |
| `双曲焦半径.typ` | 双曲线焦半径公式：左右支分情形、证明、推论与典型应用 |

| `椭圆函数点差法.typ` | 椭圆、双曲线、抛物线的点差法结论、使用条件与典型例题 |
| `蒙日圆及其反向应用.typ` | 蒙日圆（准圆）定理的代数证明与反向结论，附综合应用题（多问、多证法）完整解答 |
| `圆锥曲线手电筒模型.typ` | 圆锥曲线“手电筒”模型：过椭圆上一点作两条互相垂直的直线，割线弦恒过定点的结论与推导 |

## 构建

```powershell
# 编译全部文档（自动跳过 template.typ）
./build.ps1

# 只编译指定文档（可省略 .typ 扩展名）
./build.ps1 -Only 圆锥曲线硬解定理

# 输出 PDF 到指定目录
./build.ps1 -OutputDir dist
```

macOS / Linux 使用等价的 Bash 脚本：`./build`（参数示例：`./build 蒙日圆及其反向应用`、`./build -o dist`）。

> 所有文档共用根目录下的 `template.typ`，用法为
> `#import "template.typ": *` 后用 `#template(...)[正文]` 包裹正文，
> 可选 `#set document(title: [...])` 在页眉右侧显示标题。
> 模板内置 `#definition`、`#important-block`、`#example`、`#theorem`、
> `#proof` 环境块，并提供页码（页脚默认“第 1 页”式）、首行缩进、
> 公式编号、字号等排版选项（详见模板文件头部注释）。
>
> 新增文档时仿照现有文档写即可，例如：
>
> ```typst
> #import "template.typ": *
> #set document(title: [题目或主题])
> #template(page-footer: "第 1 页")[ ……正文…… ]
> ```

编译产物为与源文件同名的 `.pdf`（已加入 `.gitignore`，不纳入版本管理）。
